# 職話直說全站 UI 預覽

在此分支執行 `python preview/serve.py`，本機瀏覽器開啟 `http://127.0.0.1:8767`。環境需安裝 Git、Python 3 和 tar，並包含基準 commit `72a5302`。

目錄列出 12 個頁面，每個頁面都有目前版和提案版。兩版共用固定測試資料，透過頁首「看目前版／看新版」切換。上傳、帳號、分析與刪除都使用模擬回應。不要輸入真實的 Email、密碼或履歷。

關閉方式：在啟動預覽的終端按 Ctrl+C。服務會移除自己生成的暫存目錄。若不採用，保留正式站當前部署即可。程式碼集中在 `design/site-preview`，只有另行核准及部署後才需要做正式版回退。部署前可記錄 Railway 當前部署 ID，回退時重部署該已知版本，再還原對應的 Git 變更。
