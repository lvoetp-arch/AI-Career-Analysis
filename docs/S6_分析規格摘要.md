# S6 分析規格摘要（摘自《AI 職涯發展企劃》Word 執行書，供 S6 使用；不必附整份 Word）

## 技能可信度與證據
- 技能等級錨點：1 了解概念、需指導；2 能完成基礎任務；3 能獨立完成常見任務；4 能處理複雜問題並改善流程；5 能主導、設計方法並指導他人。每項技能同時顯示「自評級別、證據摘要、待驗證事項」，不得把自評直接標成 AI 已證實能力。
- MVP 不產生虛構的 92% 能力可信度；若要表示證據強弱，使用「充分／部分／不足」及理由。

## 分析輸出要求
- 建立技能證據清單與可轉移能力；推薦 3 個「值得探索的職涯方向」，而非保證錄取的職務。
- 每個方向須輸出：推薦原因、履歷證據、主要差距、入門行動、可能風險與不確定性。
- 對資料不足或矛盾的履歷，先提示補充資料；不能以沒有依據的性格推測補洞。
- LLM 應輸出可驗證 JSON；後端以 Schema 驗證、限制字數與枚舉值，**拒絕未引用證據的技能結論**。長任務可先用同步請求加逾時提示；若效能不佳，再導入 Queue。
- 流程第 ⑥⑦ 步：AI 依證據與偏好產生三個方向；顯示每個方向的理由、證據、待補足技能、30／60／90 天行動建議。

## 風險對策
- LLM 幻覺與不一致 → Schema、證據引用、人工確認、測試資料集。
- 技能分數不可靠 → 自評與證據分開。

## 測試案例（與分析相關者）
- T04 履歷未寫技能熟練度 → 不自動宣稱已驗證等級
- T05 修改工作年資／技能 → 重新分析使用最新已確認資料
- T07 LLM 超時／回傳不合法 JSON → 可重試、保留輸入、不顯示假報告
- T08 不同帳號讀取他人報告 → 拒絕存取

## 完成定義（與分析相關者）
能輸出三個有證據理由的職涯方向；錯誤處理、帳號隔離可驗證。
