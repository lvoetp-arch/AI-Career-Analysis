## 每個分站開新 session 時
1. 貼上該站的提示詞檔全文。
2. 附上該站「附檔」清單列出的檔案；契約在 `docs/00_總管理與共用契約.md`。
3. 完成後，把 `docs/handoff/S?.md` 上傳給主 session 審查；審查通過後由你自己合併。
4. 提示詞檔放在 `docs/mgmt/`；已完成的站（S0、S1、S2）檔案保留作歷史紀錄。

## 規則
- 分站不得改契約；要改，寫在交接摘要的「契約變更請求」。
- 分站不得動別站擁有的檔案（契約 §5）。
- 測試用履歷一律是虛構履歷；真實履歷永遠不進 repo、不進免費額度的 LLM。
- 每次 commit 前看 `git status`；只用明確檔名 `git add`，不用 `git add .`。
