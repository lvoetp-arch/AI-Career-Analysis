## 美術與內容規則

1. 玩家可見的角色姓名、黨派、Boss 標題、技能說明、劇情對話及宣傳素材，均使用上述虛構名稱。
2. 使用者提供的「立院攻防戰・揭弊戰神」徐巧芯圖片，已被確認為 G0-03 的 B2-R 正式**美術品質基準**；它是完整戰鬥畫面參考，並非可直接使用的分層角色素材。原圖中的真實姓名、政黨標誌及 UI 文字不直接沿用。
3. 保留首批三位 Boss 已批准的技能功能及場景方向；命名調整不等於重新設計技能或擴充製作範圍。
4. 黨派標誌與旗幟採自行設計的虛構識別，不直接使用現實政黨官方徽記。
5. 角色與事件屬政治戲仿；不得把未經證實的指控寫成事實。諧音改名並不保證免除肖像、名譽、商標或著作權等法律風險。
6. 正式角色立繪不可烘焙戰鬥 UI、文字或符石盤；素材需經人工批准後才能進入遊戲正式資產目錄。
