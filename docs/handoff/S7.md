# S7 交接摘要

## 完成項目

- `frontend/report.html` 讀取已儲存的分析結果。手機使用手風琴，桌面使用可鍵盤操作的頁籤。
- `frontend/sample_report.html` 讀取虛構資料 `frontend/sample/analysis_sample.json`，免登入並沿用同一套 `frontend/js/report.js` 與 `frontend/css/report.css`。
- 報告顯示方向、證據強弱與理由、可展開的來源、自評與差距、條件吻合度、風險、行動及可檢驗產出。歷史、匯出入口顯示為停用。
- `backend/app/services/report/` 從分析快照取出證據名稱。 `backend/tests/s7/` 驗證範例符合 Schema、報告讀取及舊資料來源回退。

## API 與契約

`GET /api/analyses/{id}` 保留原欄位，附加 `career_input_id` 供失敗重試，以及 `evidence_labels` 供報告顯示人可讀的來源。例如 `{"resume":{"work_experience[0].title":"工作經歷：虛構紙飛機商店"}}`。標籤只從登入者有權讀取的分析列產生。回應不包含完整快照。請主 session 將兩個欄位補列到契約 §8。這是本分支對 S6 共用路由的必要擴充，便於同一分支驗證報告流程。

## 待接續與決策

- 首頁屬共用檔案。請將既有的「先看範例報告（準備中）」按鈕改成連結 `sample_report.html`。
- 首頁的「用範例履歷試試」需同時確認可納入版控的虛構 R1 fixture，以及免上傳後如何建立登入者的確認版履歷。此分支可直接看範例報告。
- 真實 Supabase 跨帳號整合驗收需專用測試帳號。歷史及匯出由 S8 接續。
- 因遠端 main 尚未合入 S6，此分支由遠端 s6-analysis 對應的提交接續，供本機整段流程測試。

## 執行與驗證

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests/s7 -ra
.\.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --app-dir backend --reload
```

開啟 `/sample_report.html` 可查看範例。登入同一測試帳號後，原有的 `/report.html?id=<analysis_id>` 可以讀取已儲存的分析，不需再次呼叫模型。

- 全套測試 349 項通過，13 項需專用帳號的 RLS 整合測試略過。
- Chromium 驗證 360、768、1200 px、桌面鍵盤頁籤、手機展開、列印版、空內容、失敗重試及文字渲染。
- 手機與桌面截圖從免登入範例頁擷取。
