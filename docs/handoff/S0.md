## 其他站如何使用 core
- **驗證**：`user_id: str = Depends(current_user)`；需要 token 時用 `Depends(current_session)`（`AuthContext.user_id/.token`）。驗證方式是把 Bearer token 交給 Supabase Auth `/auth/v1/user`。
- **資料庫**：`db: Db = Depends(get_db)`；`db.select/select_one/insert/upsert/update/delete(table, ...)`，使用者 JWT、RLS 生效，且自動加 `user_id` 條件；`update` 回空列表 = 找不到，請回 `NOT_FOUND`。刪檔、清理、用量用 `admin: AdminDb = Depends(get_admin_db)`，每個方法必須傳 `user_id`：`upload_resume_pdf / download_resume_pdf / delete_resume_pdf / signed_resume_url`、`select/update/delete`。`resume_storage_path(user_id, file_id)` 產生契約規定的路徑。
- **LLM**：`llm: LLMClient = Depends(get_llm)`；`llm.complete(system, user) -> str`。失敗拋 `LLMError`（LLM_ERROR），逾時拋其子類 `LLMTimeoutError`（S6 可轉成 ANALYSIS_TIMEOUT）。Schema 驗證失敗的重試由呼叫端負責。
- **速率限制**：`dependencies=[Depends(rate_limit("parse"))]`（或 `"analysis"`）；若要先檢查同意再扣額度，在 handler 內呼叫 `request.app.state.rate_limiter.consume(user_id, "parse")`。
- **錯誤**：`raise AppError(ErrorCode.NOT_FOUND)`，可帶 `message`、`details=[{"path","message"}]`。
- **所有 core 都是同步 API**，router 請用 `def`（FastAPI 會放進執行緒池）。
- **測試**：`make_app` fixture（假驗證 token-a / token-b、假 LLM、記憶體計數），`FakeLLMClient`、`FakeTokenVerifier`、`InMemoryUsageStore`。

## 追加（契約 v0.3）：LLM 供應商
- `core/llm.py` 預設使用 Gemini（`GeminiLLMClient`，REST，金鑰放標頭）；`LLM_PROVIDER=anthropic` 可切回 Anthropic。介面不變：`llm.complete(system, user) -> str`。
- 環境變數：`LLM_PROVIDER`（預設 gemini）、`GEMINI_API_KEY`、`GEMINI_MODEL`、`GEMINI_THINKING_BUDGET`（選填）；Anthropic 的 `ANTHROPIC_API_KEY`、`CLAUDE_MODEL` 只在 `LLM_PROVIDER=anthropic` 時才需要。
- 注意：Gemini 2.5 的「思考」token 會佔用 `LLM_MAX_TOKENS`。若輸出被截斷，調高 `LLM_MAX_TOKENS` 或把 `GEMINI_THINKING_BUDGET` 設為 0（2.5-pro 不能設 0）。
